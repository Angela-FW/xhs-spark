# 重启笔记

面向「37 岁、双非、离职重启、正在找工作」人设的小红书**文案 + 一年内容规划**工具。支持感悟入库、数据/对话校准（预览后确认），以及 Pollinations **免费封面生图**。不生成视频。不需要自备服务器。

## 本地运行

```bash
npm install
npm run dev -- --port 43123 --hostname 127.0.0.1
```

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

数据保存在浏览器 `localStorage`。请用页头「导出备份 / 导入备份」防止清缓存丢失。

## 功能

| Tab | 作用 |
|-----|------|
| 日历 | 自 2026-09-09 起的四阶段周历（建立信任 → 简历与焦虑 → offer与试岗 → 叙事收束） |
| 感悟 | 粘贴零散想法 → 润色 → 关键词路由到支柱并挂到未来文章 |
| 对话 | 自然语言改规划 → 预览 → 确认应用 |
| 校准 | 录入小红书数据 + 看法 → 预览未来改版 → 确认 |
| 生成 | 选中篇目生成标题/正文/标签，并生成竖版封面图 |

### 内容阶段说明

文中 Q1–Q4 指**内容阶段**，不是 2026 公历季度。你已在求职中：前 4 周压缩「建立信任」并与简历焦虑并行。

### 封面生图

- **纯文生图**：按笔记主题调用 Pollinations  
- **基于参考图**：在「生成」页上传你的照片/实拍，或填公网图片链接，再点「基于参考图生成封面」（图生图，保留人物/构图倾向）  
- 免费接口可能限流；上传失败时可填可选 API Key  
- 不生成视频成片

### 上线（可选）

无自有服务器也可：用 Vercel / Netlify 等免费托管部署本 Next.js 项目。本机使用则无需部署。

## 技术栈

Next.js · TypeScript · Tailwind · shadcn/ui
