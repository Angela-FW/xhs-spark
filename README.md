# 爆文工坊 · 小红书爆款文案

按主题、风格和人设，一键生成小红书风格的标题、正文、话题标签与封面思路。纯前端模板引擎，无需 API Key。

## 本地运行

```bash
npm install
npm run dev -- --port 43123
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

## 怎么用

1. 填写主题 / 产品名  
2. 选择内容风格（种草、避坑、干货、测评、故事、对比）与语气人设  
3. 补充人群、卖点、关键词  
4. 生成后点选标题，一键复制整篇笔记  

也可点「填入示例」快速体验流程。

## 技术栈

- Next.js (App Router) + TypeScript  
- Tailwind CSS + shadcn/ui  

生成逻辑在 `src/lib/xhs-copy.ts`，可按自己的品类继续扩展模板。
